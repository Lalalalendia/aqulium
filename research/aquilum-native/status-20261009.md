# Aquilum Native: concrete feasibility campaign

**Working branch:** [experiments/aquilum-native-strangler](https://github.com/Lalalalendia/aqulium/tree/experiments/aquilum-native-strangler). Existing main/Tauri editor was not modified.

## Completed implementation

- Real shared Rust backend adapter around `aquilum-core::Core` and `DocumentHub`, rather than a copy/reimplementation of storage.
- Iced 0.14 multiline text editing, tab selection, explicit Save, dirty flag, guarded Reload.
- GPUI 0.2.2 paged Markdown viewer, tab selection, append-test-line, Save via the same Rust adapter. **This is not full GPUI keyboard editing; no UI performance winner should be declared yet.**
- Source and migration gates in `aquilum-native/`.
- Reproducible 1/5/20 MiB UTF-8 Markdown fixture generator and a Windows process memory sampling script in `research/aquilum-native/`.

## Proven checks

- [Linux shared-core tests](https://github.com/Lalalalendia/aqulium/actions/runs/37970659152): 3 passed, 0 failed, including persistence and stale-version rejection.
- [Windows shared-core tests](https://github.com/Lalalalendia/aqulium/actions/runs/37970659152): 3 passed, 0 failed.
- [Iced Windows Release](https://github.com/Lalalalendia/aqulium/actions/runs/37971290832): successful; 16,102,912-byte executable, present in Actions artifacts. This is compilation, not a full keyboard/mouse acceptance test.
- GPUI compile fixes implemented for typed ElementId and Stateful scroll/click controls; newest [Windows CI run](https://github.com/Lalalalendia/aqulium/actions/runs/37972110760) is the validation gate. Do not mark GPUI as built until this run is green.

## Memory comparison boundaries

The available benchmarks measure native process Working Set and private bytes, plus approximate time to create a window HWND; those are not real keyboard-to-pixel metrics or GPU dedicated memory. Until GPUI provides fully editable multiline content equivalent to Iced, process RAM comparisons are **smoke diagnostics only**, not a choice of GUI library.

**Next development gate:** functional GPUI text input/selection/IME and matching native Markdown editing protocol, then Windows user-action tests and fair Tauri baseline measurement.
